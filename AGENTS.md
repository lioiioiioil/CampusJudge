# CampusJudge

Backend пишется на Go. Frontend — HTML/CSS/JavaScript без обязательной сборки.
Хранение — PostgreSQL при заданной `CAMPUS_DATABASE_URL`, иначе локальный JSON.
Переход на PostgreSQL разрешён Романом 23 ноября 2026 года. CI без поручения
не добавлять. Перед изменением хранилища или схемы прочитать
[контракт PostgreSQL и перехода с JSON](docs/postgresql.md).
Для контейнерного выпуска и обновления читать [руководство развёртывания](docs/deployment.md).
Скачиваемые образы публикуются в GitHub Releases после проверок из чистого коммита;
серверное развёртывание и поддержка Podman отдельно не подразумеваются.

Разработка идёт проверяемыми шагами: реализовать шаг, проверить, просмотреть diff,
сделать отдельный коммит и отправить его на GitHub. Не переписывать историю и не
создавать искусственные коммиты задним числом. Проверенные и запланированные
возможности описывать отдельно. Не коммитить рабочие данные, исходники посылок,
секреты или личные сведения учеников. Не запускать недоверенный код на хосте API.
