# CampusJudge

Backend пишется на Go. Frontend — HTML/CSS/JavaScript без обязательной сборки.
Первая версия использует локальные файлы: не добавлять БД или CI без поручения.

Разработка идёт проверяемыми шагами: реализовать шаг, проверить, просмотреть diff,
сделать отдельный коммит и отправить его на GitHub. Не переписывать историю и не
создавать искусственные коммиты задним числом. Проверенные и запланированные
возможности описывать отдельно. Не коммитить рабочие данные, исходники посылок,
секреты или личные сведения учеников. Не запускать недоверенный код на хосте API.
