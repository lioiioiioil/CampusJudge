# CampusJudge

Автономная платформа для преподавателя программирования: темы, домашние задания,
контесты и история решений учеников. Backend на Go, браузерный интерфейс без сборки.

## Для кого

Для занятий в кружке, школе, лагере и индивидуального преподавания. Преподаватель
проходит тему, открывает домашнее задание и видит решения и результаты каждого
ученика. Участники контеста решают задачи и видят таблицу результатов.

## Разработка по шагам

Проект развивается последовательными коммитами. Каждый законченный шаг проверяется
до коммита и публикации. Запланированные возможности не считаются реализованными.

1. **Основа и границы продукта** — описание сценариев, архитектуры и плана.
2. **Рабочее ядро на Go** — файловое хранение, вход, роли, темы, домашние задания,
   контесты, посылки и ручная проверка.
3. **Интерфейс преподавателя и ученика** — полный сценарий занятия в браузере.
4. **Автоматическая проверка** — отдельная среда выполнения, языки, тесты,
   ограничения и результаты. Отправленный код не запускается процессом веб-сервера.
5. **Проверка целого продукта** — сохранность после перезапуска, разграничение
   доступа, контест, документация запуска и честное описание ограничений.

На первом этапе нет БД, CI и облачных зависимостей. Данные хранятся локально;
рабочие данные и решения не публикуются в Git.

## Статус

Начальный этап: определены сценарии и границы. Запускаемое приложение появится
в следующем шаге. См. [архитектуру](docs/architecture.md) и [журнал разработки](docs/development.md).
